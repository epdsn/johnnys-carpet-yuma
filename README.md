# Johnny's Carpet & Flooring — Yuma

Fast presentation site built with Astro + Tailwind CSS.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Before launch
Replace placeholder visual treatments with approved business/project photos; verify business copy, service list, hours, phone/address, social links and testimonials with the client; connect estimate/contact form; add analytics and final SEO/schema.
